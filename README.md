# cfDNA_deconv v1.0.0

A python package for deconvoluting cell-free DNA (cfDNA) composition from methylation data generated by short-read or Nanopore sequencing

This tools has been tested in Python 3.8.12 environment 


## Key features
 - Highly interpretable results based on ReadsRatio and RPKM metrics
 - Applicable for short-read and Nanopore sequencing data
 - Configurable hg19/hg38 reference builds and U25/U250 marker sets for 36/40 cell types
 - Robust performance across whole genome sequencing and target sequencing data


## Installation
### Prerequisites
- Conda (Miniconda/Anaconda) (Tested in Python 3.8.12)
- Linxu-based OS system (tested on GNU bash, version 4.4.20, x86_64-redhat-linux-gnu)
- Git (for installing RLM and mbtools)

### Step 1: Create a Conda environment
```dotnetcli
conda create -n cfDNA_deconv_env
conda activate cfDNA_deconv_env
```
### Step 2: Install external dependencies
Install RLM
```dotnetcli
git clone --recurse-submodules https://github.com/sarahet/RLM.git
mkdir build & cd build
cmake RLM
make
```
Install mbtools
```bash
git clone https://github.com/jts/mbtools.git
cd mbtools
cargo build --release
```
Install Samtools
```bash
conda config --add channels bioconda
conda config --add channels conda-forge
conda install samtools -c bioconda
```
### Step 3: Install cfDNA_deconv via Conda
```bash
# Clone code from github repository
git clone https://github.com/jasonwong-lab/cfDNA_deconv.git
cd cfDNA_deconv 
pip install . --no-cache-dir --force-reinstall 

# Build and install the Conda package:
conda build conda-recipe/
conda install --use-local cfDNA_deconv
```
### Step 4: Verify installation
```bash
cfDNA_deconv --help
```


## Usage
### For short-read sequencing data
```bash
cfDNA_deconv short-read \
  --marker-dir ./supplemental/markers \
  --ref-dir /path/to/reference \
  --bam-file ./supplemental/examples/Test_WGBS_sort.bam \
  --output-dir ./results/shortread \
  --genome hg19 \
  --marker-set U250_36celltype \
  --mode PE \ 
  --aligner bismark \ 
  --cores 8
  ```
### For Nanopore sequencing data
```bash
cfDNA_deconv nanopore \
  --marker-dir ./supplemental/markers \
  --ref-dir /path/to/reference \
  --mbtools-path /path/to/mbtools \ 
  --bam-file ./supplemental/examples/Test_Nanopore_sort.bam \
  --output-dir ./results/nanopore \
  --genome hg19 \
  --marker-set U250_36celltype \
  --cores 8
  ```

## Notes
The repository includes marker sets under `./supplemental/markers`. `--marker-dir`
may also point to another root containing `<genome>/<marker-set>_marker`
directories, or directly to one marker-set directory containing
`ReferenceList.txt`. Both commands write `ReadsRatio/<sample>.txt` and
`RPKM/<sample>.txt`.

Supported marker sets are `U25_36celltype`, `U25_40celltype`,
`U250_36celltype`, and `U250_40celltype`. A selected reference directory must
contain the matching FASTA file, such as `hg19.fa` or `hg38.fa`. Please note that `U250_36celltype`
marker set is not available for hg38 reference as it's not provided by the original publication.
